Xbox Game Pass on Microsoftin pelitilauspalvelu, joka myydään Suomessa kahdessa tasossa: PC Game Pass (8,99 e/kk, yli 300 PC-peliä) ja Game Pass Ultimate (12,99 e/kk, yli 400 peliä konsolille ja PC:lle, sisältää pilvipelaamisen ja EA Playn). Hinnat, tilaustasojen erot ja peruutusoikeus on kerrottu selkeästi suomeksi, mutta koko pelikirjastoa ei voi selata ilman kirjautumista.

Vahvuudet

  • Hinnat ja tilaustasojen erot esitetty selkeästi suomeksi: PC Game Pass 8,99 e/kk, Game Pass Ultimate 12,99 e/kk
  • Peruutusehdot ja hyvitysoikeus (30 pv) kerrottu julkisesti tilaussivulla
  • Live-chat-tuki saatavilla vuorokauden ympäri ilman ajanvarausta

Kehityskohteet

  • Koko pelikirjastoa ei voi selata ilman Microsoft-tiliin kirjautumista
  • Puhelin- tai sähköpostitukea ei tarjota; ainoa kanava on verkkokeskustelu
  • Riippumatonta arviota tai sertifiointia ei esitetä sivustolla
